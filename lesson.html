How to compare two folders with Python

Short answer

You copied a folder as a backup, or two folders have drifted apart, and you want to know what differs. A quick check that looks at file size and modified time can say two files are the same when their contents are not. This lesson builds a small read-only Python tool that lists files only in one folder and files that differ, reading the files byte by byte by default, and shows exactly what the quick shortcut misses.

Follow along and build it step by step. You add each file yourself, run each command, and see the real recorded result.

Common mistakes

  1. Trusting a quick size-and-date check. The Python documentation says its default shallow mode treats two files as equal when their size and modified time match. The practice folders contain a file that this misses.
  2. Assuming same size means same content. Two files can be the same size and hold different text. Price 100 and price 900 are the same length.
  3. Ignoring what was not compared. A top-level comparison says nothing about files inside subfolders. The final tool looks inside the subfolders it can read. Links, junctions and special files are listed as skipped, and a folder it cannot list is reported as INCOMPLETE, so a clean-looking result is not mistaken for a full one.
  4. Treating a clean result as a full match. The tool compares file contents. It does not compare permissions, owners or other file details, and it does not follow links or junctions.

Frequently asked questions

How do I compare two folders with Python?

List the files in both, find the names that are only on one side, and compare the contents of the names that are on both. This lesson builds a small tool that does that and reports the result.

Will this change my files?

No. The tool only reads the files. A test checks that two small test files have the same bytes and the same modified time before and after a run. That is the only evidence for this claim.

Why can a quick check miss a change?

The Python documentation says that in shallow mode two files are taken as equal if their size and modified time match. A change that keeps the size and the time can slip through. The practice folders show one.

Is byte by byte always better?

It is more reliable, because it reads the contents, but it takes longer on large folders. The tool offers a quick option, and says plainly what it trusts.

Does it compare file permissions or follow links?

No. It compares file contents only. Links, junctions and special files such as named pipes are listed as skipped and are never opened. Empty folders are listed. A folder it cannot read is reported as INCOMPLETE.
